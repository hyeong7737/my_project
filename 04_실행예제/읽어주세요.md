# 실행 예제와 출력 해석

## 통합예제

필수 왕복 구간, 사각형, 선택적 막다른 길이 함께 있는 지도다. 원본 운영 코드에서 14종 스펙트럼과 2개의 최적 횟수 벡터를 확인한 입력이다.

- 지도.json: 노드·도로 형태의 지도 입력.
- 지도행렬.json: 같은 지도를 R_map과 메타데이터로 표현한 입력.
- 전체실행.json: 원본 운영 코드의 완료 결과 복사본.
- 검증요약.json: 원본의 자동 검증과 통합 결과 요약.

## 독립 실행

현재 작업 폴더를 이 정리 폴더의 최상위로 두고 실행한다.

```powershell
python 실행.py --input "04_실행예제/통합예제/지도행렬.json" --output "04_실행예제/복사본실행.json"
python 실행.py --input "04_실행예제/통합예제/지도.json" --output "04_실행예제/지도직접입력_실행.json"
python 복사본_검증.py
```

실행.py는 새 알고리즘이 아니라 복사한 spectral_pipeline.solve_spectral_map을 호출하는 짧은 실행 도구다. 원래 지도 JSON을 주면 복사한 encode_whole_map을 먼저 호출한다. 상위 원본 폴더를 import하지 않는다.

## 주요 출력

| 경로 | 의미 |
|---|---|
| complete | 스펙트럼 전체 생성과 모든 최적 묶음 역복원의 완료 |
| optimal_time_certified | ⑤ 전체 생성이 완료되어 최소 시간이 인증됨 |
| all_optimal_routes_recovered | 모든 선택 스펙트럼의 모든 m을 복원했는지 |
| generation.spectra | 서로 다른 정확 계수 벡터와 시간, 존재 증인 |
| optimal_route_counts | 원래 도로 순서의 모든 최적 이용 횟수 벡터 |
| inverse_results | 각 최소 스펙트럼에 대응하는 행렬과 회로 결과 |

종료 코드 0은 완료, 3은 유효한 부분 결과, 2는 입력 등의 오류다. 시간·상태 한도에 걸리면 반환된 일부 결과를 전체 정답으로 취급하지 않는다. 같은 시간의 다른 스펙트럼은 모두 결과에 포함된다.

## 행렬설명용_3노드

가게와 집 두 개의 직선이며 w=(2,3), δ=(0,1,2), 유효 m=(2,2)이다. 시간은 13틱이다.

복사본_검증.py가 다음을 정확 연산으로 생성하고 검산한다.

- 지도.json, 지도행렬.json.
- 경로와_모든행렬.json: R, D, Kbar, C_phys, K_phys, m과 시간.
- LC회로.json: 정규 소자 표.
- 목표스펙트럼.json: 정확 특성다항식 계수와 모멘트.

이 예제와 복사본 검증은 동작 확인용이다. 기존 알고리즘과의 성능 비교 실험이 아니다.
