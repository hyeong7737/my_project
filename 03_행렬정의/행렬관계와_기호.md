# 세 종류 행렬의 관계와 공통 기호

이 정리본은 새 행렬 규칙을 발명한 것이 아니라 현재 실행 코드의 표현을 정리한 것이다.

| 구분 | 실제 표현 | 복원에 함께 필요한 것 |
|---|---|---|
| 전체 지도행렬 | R_map=R(1), n×n | 노드 라벨·좌표·집 여부·가게·단위 |
| 경로행렬 | R(m), n×n; 기본 경로 저장값은 m | 원래 지도와 도로 순서 |
| LC 회로 구조 표 | 노드 n×8, 도로 p×7 | 표에 메타데이터와 비활성 도로 기본값도 포함 |
| LC 물리 행렬 | C_phys, K_phys; 각각 n×n | 소자 단위와 좌표/도로 메타데이터 |
| LC 스펙트럼 계산 행렬 | D 또는 그와 유사한 정확 유리수 R | 경로 복원에는 원래 지도 필요 |

경로행렬 R과 LC 계산행렬 R은 **같은 수학적 행렬을 서로 다른 관점으로 부르는 것**이다. 별개의 세 행렬을 곱해야만 알고리즘이 작동하는 구조가 아니다. 회로 구조 표의 종류 코드 자체를 고유분해하지 않는다.

```text
지도 데이터 ──encode_whole_map──> R_map + 메타데이터
   │                                      │
   │                  decode_whole_map ───┘
   │
   ├── 공통 행렬족 R(m) ──⑤ 제약식──> 실현 가능한 스펙트럼 계수들
   │                                  │
   │                           ⑥ 최소 시간 묶음 선택
   │                                  │
   └───────────────────────> ⑦ 정확 역탐색
                                      │
                         m ↔ 정확 R(m) ↔ 정규 LC 표
                                      │
                         Kbar, D, C_phys, K_phys
```

## 공통 기호

| 기호 | 크기 | 정의 |
|---|---|---|
| n, p | 정수 | 지도 노드 수, 실제 도로 수 |
| w, δ | p, n | 정수 이동 시간, 집당 일회 지연 |
| a | n | a_i=1+δ_i |
| H | n×n | diag(a) |
| B | n×p | 도로 열마다 +1,−1인 접속행렬 |
| g | p | w_e/(a_u+a_v) |
| m | p | 도로 이용 횟수, 통합 탐색에서는 0·1·2 |
| Kbar | n×n | I+B diag(gm)Bᵀ |
| S | n×n | diag(sqrt(a)) |
| R | n×n | H Kbar, 정확 유리수 행렬 |
| D | n×n | S Kbar S, 대칭 양의 정부호 행렬 |
| C_phys | n×n | C★H^(-1) |
| K_phys | n×n | Kbar/L★, 역인덕턴스 행렬 |
| μ | n | D와 R의 무차원 고윳값, 중복도 포함 |
| c | n+1 | (1,c_1,...,c_n), 특성다항식의 내림차순 계수 |
| E | n | E_k=d_k(−1)^k c_k, Z3 출력용 정수 계수 |
| t★, L★, C★ | 양의 유리수 | 1틱의 초, 기준 인덕턴스 H, 기준 정전용량 F |

`R=S D S^(-1)`, `μ=L★C★ω²`, `T=t★(Σμ−n)=t★(−c_1−n)`.

접속행렬 B의 방향을 반대로 잡아도 B diag(gm)Bᵀ는 같다. 실제 도로가 단방향이라는 뜻은 아니다. R이 비대칭일 수 있어도 유사한 D는 대칭이며 양의 실수 고윳값을 갖는다.

## 일대일 대응이 성립하는 정확한 범위

원래 지도와 노드/도로 라벨, 소자 기준값이 고정된 상태에서 m↔R(m)↔정규 LC 표가 일대일이다. 고윳값 집합만으로는 여러 m과 R을 구분하지 못하며, 그 다가 관계를 ⑤·⑦에서 사용한다.

R_map의 메타데이터나 R(m)의 원래 지도를 버린 상태까지 일대일이라고 주장하지 않는다. 같은 시간이라고 반드시 같은 스펙트럼인 것도 아니다.
