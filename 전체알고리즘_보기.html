전체 알고리즘 정리

2026-09-20 현재 운영 코드의 정리본. 현재 명세의 전체 실행 구현은 완료, 기존 알고리즘과의 종합 성능 비교는 다음 단계다.

읽는 순서

1. 전체 알고리즘 흐름: 전체 플로우 차트와 요소별 설명.

2. 아래 세부 알고리즘: 각각 플로우 차트, 주요 행렬·조건, 원본 py 복사본.

3. 행렬 정의: 지도행렬, 경로행렬, LC 회로 표현의 구분과 변환.

4. 실행 예제와 복사본 검증 결과.

파일 형식과 범위

각 설명은 HTML과 Markdown을 함께 제공한다. HTML은 SVG 플로우 차트를 포함해 인터넷 없이 볼 수 있다. Mermaid 원본은 흐름도.mmd, 그림은 흐름도.svg다.

운영에 연결되는 Python 모듈 12개를 원본 그대로 복사했다. 실행.py와 복사본_검증.py는 정리본을 독립 실행·확인하기 위해 추가한 도구이며 새로운 경로 탐색 알고리즘이 아니다. 코드 복사목록의 SHA-256으로 원본과의 동일성을 확인한다. 이후 원본 수정이 이 폴더에 자동 반영되지는 않는다.

통합 실행에서는 BDD, 블록 분해, 기존 경로 DP를 사용하지 않는다. ⑦의 교대 투사는 꺼져 있다. 미래 성능 비교의 기준 알고리즘도 이번 정리본에는 새로 만들지 않았다.

독립 실행

아래 명령은 이 정리 폴더를 현재 작업 폴더로 두고 실행한다.

python -m pip install -r requirements.txt
python 실행.py --input "04_실행예제/통합예제/지도행렬.json" --output "04_실행예제/복사본실행.json"
python 복사본_검증.py

requirements 설치는 의존성이 없는 환경에서 필요하다. Python 3.13.2에서 검증했다. 복사본 실행은 상위 원본 소스를 import하지 않는다.
